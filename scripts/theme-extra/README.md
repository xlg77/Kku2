# 추가 주제 단어

원본 끄투 DB 에 없는 주제(넷플릭스, 원신, 직업, 성어 …)의 단어를 여기에 적습니다.
`curated.txt` 는 Claude 가 아는 범위에서 직접 적은 목록이라 **전체가 아닌 일부**이고, 틀린 단어가 있을 수 있어요. 고치거나 더 적어 주세요.

- 확장자 `.txt` 또는 `.tsv`
- `@주제 이름` 줄 다음에 공백으로 나눈 단어들 (한 줄에 여러 개 가능), 또는 `주제<TAB>단어` 한 줄씩
- 주제 이름은 `src/engine/themes.js` 의 `THEME_NAMES` 와 똑같아야 합니다. (틀리면 빌드가 어디서 틀렸는지 알려 줍니다)
- 단어는 한글 2글자 이상, `#` 로 시작하는 줄은 무시됩니다.
- 적은 뒤 `npm run themes` (루트에 원본 `db.sql` 필요)를 돌리면 `public/data/themes/` 에 합쳐집니다.
